Panduan Database Google Spreadsheet

5 langkah mudah menghubungkan database cloud gratis

1
Buat Google Spreadsheet Baru Buka sheets.new di browser Anda, lalu beri judul spreadsheet misalnya Jurnal Ibadah AMWA - Database.
2
Buka Editor Apps Script Di menu atas Google Sheets, klik menu Ekstensi (Extensions) > Apps Script.
3
Tempel Kode Google Apps Script Hapus semua isi bawaan di editor Apps Script, lalu salin seluruh kode dari file google-apps-script.js.
google-apps-script.js (Tersedia di folder aplikasi)
Setelah ditempel, simpan dengan menekan Ctrl + S.
4
Deploy Sebagai Web App Klik tombol biru Deploy (Terapkan) > New deployment. Pilih tipe Web app:
  • Execute as: Me (email Anda)
  • Who has access: Anyone (Siapa saja)
Klik Deploy, lakukan otorisasi (Authorize access), lalu salin Web App URL yang berakhiran /exec.
5
Tempel & Simpan di Aplikasi Tempelkan Web App URL tersebut ke kolom URL Web App di menu Akun aplikasi ini, lalu klik Simpan & Hubungkan. Data akun dan catatan ibadah Anda otomatis tersinkronisasi ke Google Sheets!
